# reflect.md RAG学习反思
路径：C路径，阅读LangChain官方文档与llm‑universe在线教程
通过对照官方2‑Step RAG流水线，我理解了本次v1.0助手本质就是先检索再生成的两阶段RAG架构。我之前写代码更多关注能不能跑出答案，通过映射表才看清自己写的每一段代码对应RAG标准架构里哪一个组件。
load‑split、embedding存储、retrieve检索、prompt组装、评估，每个模块都可以独立替换。比如embedding可以切换nomic‑embed‑text或者云端嵌入模型，知识库可以更换不同学科资料，不需要大规模修改上层业务代码，模块化组装的思路给我很深启发。
同时我也注意开源许可证问题：可以学习llm‑universe的设计思路，但不能直接复制代码提交作业。目前我的项目评估手段只有简单的幻觉对照表，没有做量化评估，这是之后需要改进的地方。后续学习Agentic RAG，希望实现模型自主判断什么时候调用检索工具，进一步完善这个中文教学问答助手。
