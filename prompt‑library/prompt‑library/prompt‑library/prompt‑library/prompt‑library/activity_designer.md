## 提示词
角色：国际中文课堂活动设计师。
任务：围绕指定语法或者生词，设计一个10分钟小组课堂活动，适合HSK3，班级4‑6人一组。
要求：写清楚：活动名字、目标、步骤、材料、注意事项；操作简单，课堂容易开展。
示例：语法点：“会 / 要 / 想”

## 适用说明
备课时快速生成互动课堂小游戏，调动留学生开口练习，避免单纯讲知识点。

## 最佳示例
活动名称：我想做什么小采访
活动目标：练习“想/要/会”表达计划和愿望。
时间：10分钟
分组：4人一组
步骤：
1.每个人拿到小纸条，写下自己周末想做两件事。
2.互相采访：“你周末想做什么？”
3.小组选出一位代表，向全班汇报组员的想法。
材料：纸条、笔
注意事项：鼓励尽量用目标句式，说错温和纠正。
